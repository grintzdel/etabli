# Photographies

Ces fichiers sont copiés de `apps/web/public/` — `marketing/` pour les
photographies, `ateliers/` pour les plaques dessinées. Les crédits et la licence
font foi là-bas : `apps/web/public/marketing/LICENSES.md`.

Ajouter une photo ici sans l'ajouter au web, ou l'inverse, fait diverger les deux
applications : un même atelier n'y porte plus la même image.
